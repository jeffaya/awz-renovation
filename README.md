# AWZ-Rénovation — site autonome

Version prête à héberger.

## Déploiement
1. Décompresser l'archive.
2. Envoyer **tout le contenu** à la racine de l'hébergement.
3. `index.html` est la page d'accueil.

## Dépendances externes
- Tailwind CSS : chargé via `https://cdn.tailwindcss.com` (choix volontaire).
- Aucune photo, logo, icône ou script métier n'est chargé depuis l'ancien site AWZ.
- Le formulaire de devis fonctionne sans service tiers : il ouvre le logiciel de messagerie du visiteur avec le message prérempli.

## Structure
- `index.html`
- `realisations.html`
- `contact.html`
- `mentions-legales.html`
- `assets/images/` : toutes les images et logos locaux
- `assets/css/styles.css`
- `assets/js/app.js`
- `robots.txt`
- `sitemap.xml`

## À savoir sur les photos
Les visuels de cette archive sont des assets locaux intégrés au package. Ils peuvent être remplacés un par un dans `assets/images/` sans modifier la structure du site.
